### Featured experiments

A few public projects that are a decent representation of the sort of things I like working on:

**🛡️ [DiffVax](https://github.com/sbartlett97/DiffVax)** — Reimplementation and experimentation around optimization-free image immunization against diffusion-based editing. The project uses a Nested U-Net to generate image perturbations in a single forward pass rather than optimizing each image individually.

**🧠 [ELECTRA PyTorch](https://github.com/sbartlett97/electra_pytorch)** — An unofficial PyTorch implementation of ELECTRA, including pretraining from scratch and reproducing the paper's GLUE results. This was one of my earlier deep dives into understanding Transformer pretraining by actually building the thing.

**🕸️ [Hands-On GNN](https://github.com/sbartlett97/hands-on-gnn)** — Implementations and experiments around graph neural networks, including GCN, GraphSAGE and GAT, alongside node, link and graph-level tasks.

**🔬 Model experiments** — You'll also find various smaller experiments around Transformers, translation, model understanding and ML tooling. Some are polished projects; others are simply me trying to answer a technical question by writing some code.
