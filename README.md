### Featured projects

A few public projects that represent what I'm interested in right now:

**🤖 [Meta-Eval](https://github.com/sbartlett97/meta-eval)** — An evaluation harness exploring behavioural invariance and the reliability of LLM-as-a-judge systems. It supports running open models locally, comparing multiple judges and separating model generation from re-judging so evaluations can be repeated without regenerating outputs.

**🧪 [LLM Fine-tune & Eval](https://github.com/sbartlett97/llm-finetune-and-eval)** — A portfolio-scale fine-tuning and evaluation harness built around Qwen2.5-3B-Instruct, LoRA/QLoRA and repeatable evaluation. The focus is deliberately on the system around the model: experiment tracking, metrics, regression detection and serving.

**🛡️ [DiffVax](https://github.com/sbartlett97/DiffVax)** — Reimplementation and experimentation around optimization-free image immunization against diffusion-based editing. Uses a trained Nested U-Net to generate perturbations in a single forward pass rather than optimizing every image individually.

**🧠 [ELECTRA PyTorch](https://github.com/sbartlett97/torch-electra)** — A PyTorch implementation of ELECTRA with configurable generator/discriminator architectures, mixed-precision training, gradient accumulation, checkpointing and hyperparameter optimisation.

**📊 [AI Usage Dashboard](https://github.com/sbartlett97/ai-usage-dashboard)** — A self-hosted dashboard for monitoring AI API spend and token usage across OpenAI and Anthropic, with SQLite persistence, project filtering and Docker deployment.

You'll also find smaller experiments around Transformers, graph ML, translation, model understanding and ML tooling.
